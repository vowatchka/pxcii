# AGENTS.md — правила работы над pxcii

## Проект

`pxcii` — конвертер изображений в псевдографику. Один бинарь, три режима: CLI, desktop, web.
Стек: Rust (edition 2021), `eframe`/`egui` для GUI, `axum` + `tokio` для web, `pyo3` для Python.
Крейты: `pxcii-core` (ядро), `pxcii` (bin), `pxcii-py` (обёртка), `xtask` (служебные команды).
Тулчейн запинен в `rust-toolchain.toml`. Единственный источник этапов — `pxcii-dev-plan.md`.
Порядок работы человека с агентами (команды `/stage`, `/verify`, выбор модели, промпты) —
раздел 7 `pxcii-dev-plan.md`.

## Жёсткие ограничения

- Только pure Rust: никаких C-зависимостей и `-sys`-крейтов с C.
- `pxcii-core` не знает про `std::fs`, `Path`, `env::` — работа с ФС только в `pxcii` и `pxcii-py`.
- GUI без persistence, web без временных файлов, никаких логов на диске.
- Один бинарь `pxcii`, GUI за фичей `gui`.

## Команды проверки (Definition of Done)

```sh
cargo fmt --all --check
cargo clippy --workspace --all-targets -- -D warnings
cargo test --workspace --all-features
cargo llvm-cov --workspace --fail-under-lines 100
cargo run -p xtask -- check-core-purity
```

## Тесты

- golden-файлы генерируются только через `xtask gen-fixtures`, руками не правятся;
- никаких сетевых фикстур, никаких `sleep` в тестах.

## Стиль

- rustfmt по умолчанию, clippy `-D warnings`;
- код и комментарии в коде — по-английски, документация и отчёты — по-русски;
- переводы строк LF: за это отвечает `.gitattributes`, файлы с CRLF не коммитить.

## Правила для любого агента (обязательные)

1. **Git-конфиг — только `git config --local`.** Глобальный (`--global`) и системный (`--system`)
   конфиг не трогать. Нужна настройка (например, `core.autocrlf`, `core.longpaths`) — менять
   её в `.git/config` этого репозитория.
2. **Ничего не устанавливать и не скачивать в систему без явного одобрения человека.**
   Запрещено самостоятельно: `cargo install`, `winget`, `choco`, `scoop`, `apt`, `brew`,
   `pip install`, установка SDK/тулчейнов, скачивание шрифтов, архивов, бинарников.
   Вместо этого — сообщить человеку: что требуется, зачем, какая команда и сколько примерно
   это займёт, и дождаться решения.
   Разрешено без согласования: `cargo build/check/test/fmt/clippy`, `cargo llvm-cov` и прочие
   DoD-команды (они лишь скачивают крейты из crates.io в `~/.cargo` — это часть сборки),
   а также `git`-операции чтения.
3. Не создавать файлов и каталогов вне рабочего каталога проекта, не менять системный PATH
   и переменные окружения.
4. Не коммитить и не пушить без указания человека. Коммит — один этап = один squash-коммит
   с префиксом `stage-N: `.
